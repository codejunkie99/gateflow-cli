## Problem Statement

The `removeFromIndices()` method properly removes an item from all indices **except** it fails to recalculate `avgDocLength`. This causes BM25 scoring to become progressively inaccurate as items are removed.

## How avgDocLength Affects BM25

The BM25 formula uses `avgDocLength` for length normalization:

```
                    IDF × TF × (k₁ + 1)
score(term) = ─────────────────────────────────────────
               TF + k₁ × (1 - b + b × (docLen / avgDocLen))
```

When `avgDocLength` is wrong:
- **Too high** → Penalizes long documents unnecessarily
- **Too low** → Boosts long documents artificially

## Fix Implementation

### Step 1: Locate the Method

Find `removeFromIndices()` in `KnowledgeStore.ts` (around line 302).

### Step 2: Add avgDocLength Recalculation

Add the following at the **end** of `removeFromIndices()`:

```typescript
private removeFromIndices(item: KnowledgeItem): void {
    this.itemById.delete(item.id);
    this.itemByFingerprint.delete(item.fingerprint);

    const tokens = this.tokenize(item);
    this.docLengths.delete(item.id);

    const seenTerms = new Set<string>();
    for (const term of tokens) {
        const postings = this.invertedIndex.get(term);
        if (postings) {
            postings.delete(item.id);
            if (postings.size === 0) {
                this.invertedIndex.delete(term);
            }
        }

        if (!seenTerms.has(term)) {
            seenTerms.add(term);
            const count = this.termDocFreq.get(term) || 0;
            if (count <= 1) {
                this.termDocFreq.delete(term);
            } else {
                this.termDocFreq.set(term, count - 1);
            }
        }
    }

    // ═══════════════════════════════════════════════════════════
    // FIX: Recalculate avgDocLength after removal
    // ═══════════════════════════════════════════════════════════
    const n = this.docLengths.size;  // Number of remaining documents
    if (n > 0) {
        let totalLength = 0;
        for (const len of this.docLengths.values()) {
            totalLength += len;
        }
        this.avgDocLength = totalLength / n;
    } else {
        this.avgDocLength = 0;
    }
}
```

### Alternative: Optimized Incremental Calculation

Instead of iterating all documents, use incremental formula:

```typescript
// More efficient but requires knowing the removed doc's length before deletion
private removeFromIndices(item: KnowledgeItem): void {
    this.itemById.delete(item.id);
    this.itemByFingerprint.delete(item.fingerprint);

    const tokens = this.tokenize(item);
    const removedLength = tokens.length;  // Save before deleting
    this.docLengths.delete(item.id);

    // ... existing term removal code ...

    // FIX: Incremental avgDocLength update
    const n = this.docLengths.size;
    if (n > 0) {
        // Formula: new_avg = (old_avg * (n+1) - removed_length) / n
        this.avgDocLength = ((this.avgDocLength * (n + 1)) - removedLength) / n;
    } else {
        this.avgDocLength = 0;
    }
}
```

**Recommendation**: Use the iterative approach for correctness. The incremental formula can accumulate floating-point errors over many operations.

            tags: [],
            keywords: [],

            source: { method: 'extracted' },

        });

        const item2 = store.addKnowledge({
            type: 'module_info',
            title: 'Long',
            content: 'one two three four five six seven eight nine ten',  // 10 tokens
            tags: [],
            keywords: [],
            scope: { global: true },
            source: { method: 'extracted' },
            confidence: 0.9
        });

        const avgBefore = (store as any).avgDocLength;

        // Remove the longer item
        store.removeKnowledge(item2.id);

        const avgAfter = (store as any).avgDocLength;

        // avgDocLength should decrease after removing the longer item
        expect(avgAfter).toBeLessThan(avgBefore);
    });
});
