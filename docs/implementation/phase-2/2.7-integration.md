## Purpose

Integrate the extraction system into the indexing pipeline so that:
1. Knowledge is automatically extracted after each index operation
2. The knowledge store is populated with structural information
3. Events are emitted for UI feedback

## Integration Point

The extraction should happen in `SVIndexerAdapter.buildIndex()` after:
1. Indexing completes (`this.project` is populated)
2. Legacy index is converted
3. Cache is updated
4. Before the method returns

### Step 2: Add Extraction After Caching

Add the following code after the cache update and event emission:

```typescript
async buildIndex(): Promise<void> {
    // ... existing indexing logic ...

    // Convert to legacy format
    this.convertToLegacyIndex();

    // Cache the result
    await this.projectCache.set(this.rootPath, this.filePaths, this.project);

    // Emit index complete event
    this.bus.emit({
        type: 'tool_result',
        tool: 'index',
        ok: true,
        summary: `Indexed ${this.project?.declarations.length ?? 0} declarations`
    });

    // ═══════════════════════════════════════════════════════════════════
    // NEW: Extract knowledge from indexed project
    // ═══════════════════════════════════════════════════════════════════
    await this.extractKnowledge();
}

/**
 * Extract knowledge from the current project into the knowledge store
 * @private
 */
private async extractKnowledge(): Promise<void> {
    // Get global knowledge store
    const knowledgeStore = getKnowledgeStore();

    if (!knowledgeStore || !this.project) {
        return;  // No store available or no project to extract from
    }

    try {
        // Create extraction options
        const options = createExtractionOptions(
            knowledgeStore.getProjectId(),
            {
                maxItemsPerCategory: 300,  // Reasonable limit for typical projects
                // Could add excludePatterns based on user config
            }
        );

        // Perform extraction
        const result = await extractFromIndex(
            this.project,
            knowledgeStore,
            options
        );

        // Emit result event
        this.bus.emit({
            type: 'tool_result',
            tool: 'knowledge_extraction',
            ok: result.success,
            summary: formatExtractionSummary(result)
        });

        // Log detailed stats in debug mode
        if (process.env.DEBUG) {
            console.log('[SVIndexerAdapter] Knowledge extraction:', result);
        }

    } catch (error) {
        // Non-fatal - log and continue
        console.warn(
            '[SVIndexerAdapter] Knowledge extraction failed:',
            error instanceof Error ? error.message : error
        );

        this.bus.emit({
            type: 'error',
            message: `Knowledge extraction failed: ${
                error instanceof Error ? error.message : 'Unknown error'
            }`,
            recoverable: true
        });
    }
}
```

## Event Flow

After integration, the event sequence will be:

```
User runs: gateflow index

1. SVIndexer.indexProject() starts
   → emit: status { phase: 'indexing', label: 'Parsing files...' }

2. Parsing completes
   → emit: tool_result { tool: 'index', ok: true, summary: '150 declarations' }

3. Knowledge extraction runs (NEW)
   → emit: tool_result { tool: 'knowledge_extraction', ok: true,
                         summary: 'Extracted 45 modules, 30 dependencies...' }

4. User sees both results in terminal
```

## Error Handling

The extraction is **non-fatal**:
- If KnowledgeStore unavailable → silently skip
- If extraction fails → log warning, emit recoverable error, continue
- Index operation succeeds regardless of extraction result
