# Module 5.1: Add Relaxed Scope Matching Mode

## Overview

| Attribute | Value |
|-----------|-------|
| **File** | `src/memory/KnowledgeStore.ts` |
| **Lines** | ~551-578 (matchesScope method) |
| **Purpose** | Allow scoped items to be retrieved with penalty |
| **Effort** | 45 minutes |
| **Dependencies** | None |

## Problem Statement

Currently, the scope matching uses **fail-closed semantics**:
- If an item is scoped to specific modules and the query doesn't provide `moduleName`, the item is **excluded entirely**
- This means valuable knowledge becomes invisible when the agent queries without full context

## Current Behavior

```typescript
// In matchesScope() around line 559-576
if (scope.modules?.length) {
    if (!query.moduleName || !scope.modules.includes(query.moduleName)) {
        return false;  // ← EXCLUDED - not returned at all
    }
}
```

**Example**: User asks "what patterns exist for reset handling?" but doesn't specify a module. All module-scoped reset patterns are hidden.

## Solution Design

Add a `relaxedScope` option that:
1. Still prefers exact scope matches (full score)
2. Returns partially-matching items with **score penalty** instead of exclusion
3. Allows global queries to see all relevant knowledge

### Step 2: Create matchesScopeWithScore() Method

Add new method that returns a score multiplier instead of boolean:

```typescript
/**
 * Check if item scope matches query, returning a score multiplier.
 *
 * @param scope - Item's scope constraints
 * @param query - Query parameters
 * @returns Score multiplier: 1.0 for full match, 0.0-0.9 for partial, 0 for no match
 * @private
 */
private matchesScopeWithScore(scope: KnowledgeScope, query: KnowledgeQuery): number {
    // Global scope always matches fully
    if (scope.global) {
        return 1.0;
    }

    let scoreMultiplier = 1.0;

    // Project scope check
    // (Usually always passes since we query within a project)
    if (scope.projectIds?.length) {
        // For now, assume we're in the right project
        // Could add projectId to query for multi-project support
    }

    // File pattern check
    if (scope.filePatterns?.length) {
        if (!query.filePath) {
            // No file context provided
            if (query.relaxedScope) {
                scoreMultiplier *= 0.5;  // 50% penalty
            } else {
                return 0;  // Strict mode: exclude
            }
        } else {
            // Check if file matches any pattern
            const matches = scope.filePatterns.some(pattern =>
                picomatch.isMatch(query.filePath!, pattern, {
                    dot: true,
                    nocase: process.platform === 'win32'
                })
            );

            if (!matches) {
                if (query.relaxedScope) {
                    scoreMultiplier *= 0.3;  // 70% penalty for wrong file
                } else {
                    return 0;
                }
            }
        }
    }

    // Module scope check
    if (scope.modules?.length) {
        if (!query.moduleName) {
            // No module context provided
            if (query.relaxedScope) {
                scoreMultiplier *= 0.5;  // 50% penalty
            } else {
                return 0;  // Strict mode: exclude
            }
        } else if (!scope.modules.includes(query.moduleName)) {
            // Wrong module
            if (query.relaxedScope) {
                scoreMultiplier *= 0.3;  // 70% penalty
            } else {
                return 0;
            }
        }
        // Exact module match: no penalty (multiplier stays 1.0)
    }

    return scoreMultiplier;
}
```

### Step 3: Update search() to Use Score Multiplier

Modify the `search()` method to use the new scoring:

```typescript
search(query: KnowledgeQuery): KnowledgeSearchResult[] {
    // ... existing candidate selection code ...

    const scored: Array<{ item: KnowledgeItem; score: number; reason: string }> = [];

    for (const item of candidates) {
        // Type filter
        if (query.types?.length && !query.types.includes(item.type)) {
            continue;
        }

        // Tag filter
        if (query.tags?.length && !query.tags.some(t => item.tags.includes(t))) {
            continue;
        }

        // Confidence filter
        if (query.minConfidence !== undefined && item.confidence < query.minConfidence) {
            continue;
        }

        // ═══════════════════════════════════════════════════════════════
        // MODIFIED: Use score-based scope matching
        // ═══════════════════════════════════════════════════════════════
        const scopeScore = this.matchesScopeWithScore(item.scope, query);
        if (scopeScore === 0) {
            continue;  // Completely excluded (strict mode or no match)
        }

        // Calculate base score
        let baseScore: number;
        if (queryTerms.length > 0) {
            baseScore = this.scoreBM25(item, queryTerms);
        } else {
            baseScore = this.scoreBasic(item);
        }

        // Apply scope multiplier
        const finalScore = baseScore * scopeScore;

        scored.push({
            item,
            score: finalScore,
            reason: this.getMatchReason(item, query, scopeScore)
        });
    }

    // Sort by score descending
    scored.sort((a, b) => b.score - a.score);

    // Return top N
    const maxResults = query.maxResults ?? 10;
    return scored.slice(0, maxResults).map(({ item, score, reason }) => ({
        item,
        relevance: score,
        matchReason: reason
    }));
}
```

### Step 4: Update getMatchReason() for Scope Penalties

```typescript
/**
 * Generate human-readable match reason
 * @private
 */
private getMatchReason(
    item: KnowledgeItem,
    query: KnowledgeQuery,
    scopeScore: number
): string {
    const reasons: string[] = [];

    // Keyword matches
    if (query.query) {
        const matchedKeywords = item.keywords.filter(k =>
            query.query!.toLowerCase().includes(k)
        );
        if (matchedKeywords.length > 0) {
            reasons.push(`Keywords: ${matchedKeywords.slice(0, 3).join(', ')}`);
        }
    }

    // Tag matches
    if (query.tags?.length) {
        const matchedTags = item.tags.filter(t => query.tags!.includes(t));
        if (matchedTags.length > 0) {
            reasons.push(`Tags: ${matchedTags.slice(0, 3).join(', ')}`);
        }
    }

    // Module match
    if (query.moduleName && item.scope.modules?.includes(query.moduleName)) {
        reasons.push(`Module: ${query.moduleName}`);
    }

    // ═══════════════════════════════════════════════════════════════
    // NEW: Add scope penalty indication
    // ═══════════════════════════════════════════════════════════════
    if (scopeScore < 1.0 && scopeScore > 0) {
        const penaltyPercent = Math.round((1 - scopeScore) * 100);
        reasons.push(`Scope penalty: -${penaltyPercent}%`);
    }

    return reasons.length > 0 ? reasons.join('; ') : 'General relevance';
}
```

## Score Multiplier Summary

| Scenario | Score Multiplier |
|----------|------------------|
| Global scope | 1.0 |
| Exact module match | 1.0 |
| Exact file pattern match | 1.0 |
| No module context (relaxed) | 0.5 |
| No file context (relaxed) | 0.5 |
| Wrong module (relaxed) | 0.3 |
| Wrong file (relaxed) | 0.3 |
| Any mismatch (strict) | 0.0 (excluded) |

## Testing Strategy

### Unit Test: Relaxed Scope Includes More Items

```typescript
describe('relaxedScope', () => {
    it('should include scoped items with penalty in relaxed mode', () => {
        const store = new KnowledgeStore(projectRoot, bus);
        await store.load();

        // Add module-scoped item
        store.addKnowledge({
            type: 'code_pattern',
            title: 'Reset pattern',
            content: 'Use synchronous reset',
            tags: [],
            keywords: ['reset', 'synchronous'],
            scope: {
                global: false,
                modules: ['uart_tx']
            },
            source: { method: 'extracted' },
            confidence: 0.9
        });

        // Strict mode: no results without module context
        const strictResults = store.search({
            query: 'reset',
            relaxedScope: false  // or omit
        });
        expect(strictResults.length).toBe(0);

        // Relaxed mode: includes with penalty
        const relaxedResults = store.search({
            query: 'reset',
            relaxedScope: true
        });
        expect(relaxedResults.length).toBe(1);
        expect(relaxedResults[0].relevance).toBeLessThan(1.0);
        expect(relaxedResults[0].matchReason).toContain('Scope penalty');
    });
});
```
